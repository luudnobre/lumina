✦ LUMINA · MEU UNIVERSO

Seu LUMINA na nuvem

Use o mesmo app na Vercel, com sua conta e seus registros em qualquer navegador atual.

01 · ANTES DE ATUALIZAR

Guarde o que você já escreveu

No app que está no ar, vá a Configurações → Exportar backup. Guarde o arquivo JSON com os registros e fotos.

Use o navegador onde você já preenchia o LUMINA. Guarde o JSON com você e mantenha esse arquivo fora do repositório.

02 · SUPABASE

Crie o banco e seu login

  1. Abra o Supabase e crie ou selecione um projeto para o LUMINA, com a Data API habilitada.
  2. No SQL Editor → New query, cole todo o conteúdo de supabase/01-estrutura.sql. Clique em Run.
  3. Em Authentication → Users → Add user → Create new user, cadastre seu e-mail, escolha uma senha e confirme o usuário. Se aparecer Auto confirm user, marque para sua própria conta.
  4. Em Authentication → Sign In / Providers, deixe Email habilitado e desative Allow new users to sign up.
  5. Em Connect ou Project Settings → API Keys, copie a URL do projeto e a Publishable key.
03 · VERCEL

Atualize o projeto que já existe

Abra o projeto do LUMINA na Vercel. Em Environment Variables, crie estas duas entradas em Production. Use Config se aparecer essa escolha.

KeyValue
VITE_SUPABASE_URLProject URL, começando por https://
VITE_SUPABASE_PUBLISHABLE_KEYChave pública que começa com sb_publishable_ ou anon legada

Copie o conteúdo da pasta extraída para a pasta do repositório que a Vercel já usa. Em Build and Deployment, confira Vite, Node.js 22.x ou 24.x, build npm run build e saída dist.

Envie as mudanças ao GitHub e aguarde Ready em Deployments. Se as variáveis foram salvas depois do deploy, clique em Redeploy.

O README.md detalha os comandos para Git e para quem publica pela CLI.

04 · PRIMEIRO ACESSO

Traga seus registros e confira

  1. Entre no endereço publicado com seu e-mail e a senha criada no Supabase.
  2. Em Configurações → Backup e transferência, use Importar backup. No mesmo endereço e navegador da versão antiga, você também pode usar Trazer dados deste navegador.
  3. Abra Espírito → Matéria, escreva um registro de teste e espere Na nuvem.
  4. Entre com a mesma conta em outro navegador. Confira se o registro apareceu.

Em Authentication → URL Configuration no Supabase, use seu endereço publicado como Site URL e adicione o mesmo endereço com / às Redirect URLs para recuperar a senha.

OPCIONAL · TESTE NO COMPUTADOR

Abra a demonstração primeiro

Com Node.js 22.12+ ou 24, abra a pasta no VS Code e rode:

npm ci
npm run dev

Abra o endereço Local do terminal. Para conectar no computador, copie .env.example para .env.local, preencha os valores e reinicie o Vite.

O código, a estrutura do banco e os testes estão na mesma pasta deste guia.
