LUMINA · GUIA DA ATUALIZAÇÃO

Seu financeiro,
mais claro.

Oi, Ludzinha! Este guia serve para atualizar o LUMINA que você já tem na Vercel e no Supabase. Leia primeiro e faça os passos com calma.

1. Guarde uma cópia do seu LUMINA

  1. Abra o site atual e entre na sua conta.
  2. Clique em Configurações → Exportar backup e guarde o arquivo em um lugar seguro.
  3. Confira que aparece Na nuvem e feche as outras abas do LUMINA, inclusive em outros aparelhos, até finalizar a atualização.

O backup contém informações pessoais. Não o envie ao GitHub. Se for restaurado depois, substitui todo o conteúdo atual, inclusive as finanças.

2. Coloque os arquivos na pasta certa

  1. Extraia o arquivo ZIP.
  2. No VS Code, abra a pasta que você já usa para o LUMINA: nela há um arquivo package.json.
  3. Copie o conteúdo da pasta extraída para essa pasta existente e aceite substituir arquivos com o mesmo nome. Copie também as pastas src, public, supabase e tests.
  4. Confira no VS Code se src/finance-core.js e src/finance-ui.js apareceram.

Mantenha sua pasta .git e seu arquivo .env.local. Este ZIP não traz senhas nem apaga seus dados do Supabase. Ele contém os arquivos completos do aplicativo: confira antes de substituir se você fez outras alterações no projeto depois da versão enviada.

3. Teste no computador

No terminal do VS Code, dentro da pasta do projeto, digite:

npm run build

Se aparecer que faltam dependências, rode npm ci e depois repita npm run build. Para abrir uma prévia no computador:

npm run dev

Abra o endereço Local mostrado no terminal. Para o modo com sua conta funcionar localmente, o .env.local existente precisa apontar para seu Supabase.

4. Atualize o GitHub e a Vercel

Se o projeto já publica pelo GitHub, confira suas alterações com git status. Se tudo estiver certo e você estiver na mesma branch que publica o site, rode:

git add .
git commit -m "Adiciona controle financeiro"
git push

Depois abra o projeto correto do LUMINA na Vercel → Deployments e aguarde aparecer Ready. Se você usa outro método de publicação, siga o mesmo que usou antes, selecionando o projeto existente.

Se o Supabase e a Vercel já estão configurados para este LUMINA, você não precisa criar outro projeto ou executar um SQL novo. O aplicativo usa o mesmo login e o mesmo documento de dados.

5. Confira seu site

  1. Abra o endereço já publicado, recarregue a página e entre com a mesma conta.
  2. Veja se suas áreas, metas e registros continuam lá.
  3. Clique em Meu financeiro no menu. No celular, toque em Mais → Meu financeiro.
  4. Cadastre uma conta e um cartão de teste. Espere o indicador Na nuvem e confira em outro navegador usando a mesma conta. Você pode editar ou excluir esses registros depois.

Se a página pedir conexão com Supabase, confira as variáveis VITE_SUPABASE_URL e VITE_SUPABASE_PUBLISHABLE_KEY em Environment Variables → Production na Vercel. Depois de alterar variáveis, faça um novo deploy. Use apenas a chave pública do projeto.

Como usar as finanças

Comece cadastrando o saldo real de cada conta e a data desse saldo. Em seguida, inclua seus cartões e os limites. Você pode registrar entradas, gastos, compras parceladas, pagamentos de fatura, dívidas, investimentos, bens e metas; tudo pode ser editado.

Uma compra confirmada no cartão já reduz o disponível após cartões pelo valor total. Ao registrar a fatura paga, o dinheiro sai da conta e a dívida do cartão diminui. A compra não é contada duas vezes. Confira o mês da primeira parcela com sua fatura.

O gráfico mostra a composição dos bens; abaixo dele há patrimônio líquido, cartões e dívidas. As metas mostram quanto falta e um prazo estimado a partir do valor mensal que você informar.

Os dados são cadastrados por você. Não há conexão automática com bancos, atualização automática das cotações nem pagamento de contas. Confira sempre os dados com seus extratos.

Proteja as alterações

Após publicar, recarregue as abas antigas em todos os aparelhos. Versões anteriores não conhecem os campos financeiros. Se o app pedir para resolver um conflito, faça backup antes de escolher uma versão para substituir a outra.

O arquivo README.md tem explicações detalhadas dos cálculos e da atualização. Se ainda não houver estrutura de Supabase, consulte GUIA-PRIMEIRA-INSTALACAO.md.

Se algo diferente aparecer na sua tela, pare nessa etapa e confira o erro antes de alterar outras configurações.
